## 판정과 한계

‘검토된 트램 정거장 5개 기준 신규 접근권 편입 후보’는 같은 반경에서 **승인된 트램 중 하나에 포함되고, 모든 1호선 역에서 벗어난 현재 상가**입니다. 상가업소번호별로 한 번만 셉니다. 기존과 동일한 구면 Haversine 거리(지구 반지름 6,371,008.8m)를 사용하며 경계는 포함합니다. 300m 또는 500m를 동시에 두 교통망에 적용합니다.

지도는 정거장별 반경 원과 상가 점의 분류를 나타냅니다. 두 교통망의 원을 실제 지리 폴리곤 차집합으로 잘라 면적을 산출한 것은 아닙니다. 후보의 업종·행정동·관련 정거장은 전체 상가로 집계하고 지도만 최대 3,000개로 표본 표시합니다. 행정동별 표는 후보 상가의 집계이며 행정동 전체가 신규 역세권이라는 의미가 아닙니다. 정거장별 표는 같은 상가가 여러 정거장에 관련되면 중복될 수 있지만 전체 후보 수는 중복 제거합니다.

공식 1호선 대표점과 트램 근사점은 위치 기준·오차가 다릅니다. 트램의 확정 위치·개통 후 영향권이나 실제 도보거리·시간을 주장하지 않습니다. 반경 경계는 좌표 오차에 민감합니다. 버스 등 다른 교통수단을 비교하지 않았으므로 기존 1호선 반경 밖을 ‘대중교통이 없는 지역’으로 해석하면 안 됩니다. 반경을 늘리면 기존 1호선 접근권도 커지므로 신규 후보 수가 반드시 늘어나는 것은 아닙니다.

감소 시나리오는 공사에 따른 도로·횡단·보행 동선 변화 가능성을 점검하는 정성적 가정입니다. 공사 구간·시기·우회 동선은 별도 확인해야 합니다. 실제 매출·유동인구·임대료·교통량 시계열 및 인과추정 없이 미래 증가율·감소율이나 창업 성공 확률을 예측하지 않습니다.

## 외부 공유 전 확인

시연본에 좌표 관리자·업로드·서버 데이터 수정 기능을 포함하지 않았습니다. API 키·비밀번호·토큰·개발용 절대경로는 정적 점검에서 발견되지 않았습니다. 시연본은 자료 오류 안내를 일반 문구로 바꾸고 `client.showErrorDetails="none"`으로 예외 상세·스택 경로 표시를 차단했습니다. 서버 로그와 호스트 파일 접근 권한까지 보증하는 보안 감사는 아닙니다. 공개 권리 확인이 남은 기존 자료가 있으므로 공개 배포 승인 완료로 간주하지 마세요. 이번 작업에서는 배포·터널·외부 공개 링크를 만들지 않았습니다.
