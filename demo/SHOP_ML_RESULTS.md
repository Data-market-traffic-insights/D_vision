# 점포 변화 학습 모델 — 첫 실험 결과

실행 후 **트램 주변 미래 상권 → 학습 모델 실험**에서 확인합니다.
서울 상권의 다음 분기 또는 1년 뒤 점포 수를 과거 관측으로 예측하는 지도학습 모델입니다.
대전 트램의 인과효과·매출·창업 성공을 예측하는 모델은 아닙니다.

## 평가 설계

- 입력 시점 t의 최근 4개 분기 점포 수, 1분기·3분기 증감, 평균·변동, 같은 분기의 업종 구성, 상권 위치·유형·자치구, 신림선 예정지 거리, 계절·운영 여부를 사용합니다.
- 대상은 `log1p(t+h 점포 수) - log1p(t 점포 수)`이며 h=1과 h=4를 각각 직접 학습합니다. 학습 후 점포 수 단위로 복원합니다.
- 입력 자료는 서울시 2021~2025년 상권별 점포 원표입니다. 음식·커피·소매·미용/세탁/수리 4개 묶음이고 커피는 음식에 포함됩니다.
- 최근 4개 분기가 연속 관측된 경우만 사용합니다. 원표에서 없는 상권·분기를 0으로 채우지 않습니다. 업종 구성 특성의 결측 대체값과 표준화는 학습 기간에서만 계산합니다.
- 현재 다른 노선 역까지 거리, 2021년 전체를 미리 요약한 pre_total, 상권 ID, 미래 실측·승하차·대전 2030 계획 수요는 학습 입력에서 제외합니다.
- **정답 시점 2021~2023년은 학습, 2024년은 모델 선택, 2025년은 최종 평가**로 고정했습니다. 2025년 결과를 보고 모델·파라미터를 다시 고르지 않았습니다.
- 학습 후보는 Ridge(alpha=10), 랜덤포레스트(120개 트리, 깊이 10, leaf 최소 25), 그래디언트 부스팅(150회, leaf 최대 15, leaf 최소 30, L2=10)입니다. seed=20261114, sklearn=1.6.1입니다. 부스팅의 무작위 검증 분할·조기 종료는 사용하지 않습니다.
- 유지 기준과 최근 3분기 선형 추세도 같은 2024년 자료로 비교 기준을 선택했습니다.

## 선택 결과와 2024년 성능

| 방법 | 다음 분기 MAE(개) | 1년 뒤 MAE(개) |
|---|---:|---:|
| 최근 점포 수 유지 | 1.1444 | 2.8660 |
| 최근 추세 연장 | 1.2993 | 4.2106 |
| Ridge | 1.8956 | 3.5710 |
| 랜덤포레스트 | 1.2290 | 3.3236 |
| 그래디언트 부스팅 | 1.2392 | 3.2179 |

학습 모델 중에서는 다음 분기의 랜덤포레스트, 1년 뒤의 그래디언트 부스팅을 고정했습니다.
두 간격 모두 2024년에는 유지 기준이 더 좋았습니다. 이 사실을 화면에 함께 표시합니다.
선택한 학습 방법을 2024년까지의 정답으로 재학습한 뒤 2025년을 평가했습니다.

## 2025년 최종 평가

| 예측 간격·지역 | 관측 수 | 학습 모델 MAE | 유지 기준 MAE | 오차 감소 |
|---|---:|---:|---:|---:|
| 다음 분기·서울 전체 관측 | 25,479 | 1.0126 | 1.0739 | 약 5.7% |
| 다음 분기·신림선 500m | 494 | 0.8332 | 0.8320 | 약 -0.1% |
| 1년 뒤·서울 전체 관측 | 25,391 | 2.3880 | 3.0393 | 약 21.4% |
| 1년 뒤·신림선 500m | 494 | 2.0114 | 2.4777 | 약 18.8% |

MAE는 상권·업종·시점 하나당 예측과 실제가 평균 몇 개 다른지를 뜻합니다.
오차 감소율은 `1 - 학습 모델 MAE / 비교 기준 MAE`이며 정확도 백분율이 아닙니다.
같은 상권이 여러 분기에 반복되고 음식·커피가 겹칩니다. 관측 수가 독립 상권 수는 아닙니다.

업종별 결과도 다릅니다. 1년 뒤 서울 전체에서 소매는 학습 모델 MAE 4.1912, 유지 기준 6.5505로 개선됐지만, 커피·음료는 1.0677 대 1.0665로 거의 같았습니다.
다음 분기 커피·음료는 학습 모델 0.4887 대 유지 기준 0.4481로 더 나빴습니다.
이 결과를 모든 업종에 유효한 모델이라고 일반화하지 않습니다.

## 입력 특성의 유용성 진단

같은 학습 방법으로 과거 점포·계절 특성만 사용한 경우와 업종 구성·위치 등을 추가한 경우를 비교했습니다.

| 간격 | 과거 점포·계절만 사용한 2025 MAE | 전체 입력의 2025 MAE |
|---|---:|---:|
| 다음 분기 | 1.0134 | 1.0126 |
| 1년 뒤 | 2.3753 | 2.3880 |

추가 특성이 큰 개선을 만들었다는 근거는 없습니다. 역 거리의 인과적 기여를 검증한 결과도 아닙니다.
이 진단을 보고 다시 모델을 고르거나 학습 특성을 바꾸지 않았습니다.

## 자료 기준 전망과 해석 한계

마지막 입력 관측은 **2025년 4분기**입니다. 그 시점 자료로 계산한 다음 분기는 2026년 1분기, 1년 뒤는 2026년 4분기입니다.
현재 날짜에 맞춘 최신 관측 전망이 아니며 2026년의 실제 변화는 입력하지 않았습니다.
학습 모델 전망과 유지 기준 전망을 함께 표시하고, 통계적 예측구간은 아직 산출하지 않습니다.

다음 분기 2025년 평가는 각 예측 시점까지의 실제 관측을 사용하는 순차 평가입니다. 2024년 말에 2025년 네 분기를 한꺼번에 예측한 성능이 아닙니다.
단일 버전 경계·지리정보를 고정한 회고 평가이며, 자료 공개 지연·과거판 개정을 재현하지 못했습니다.
서울의 기존 관측 상권을 시간으로 나눠 평가한 것으로 미관측 상권·다른 도시의 성능을 검증한 것은 아닙니다.
대전 자료는 연간에 가까운 네 시점이고 업종·공간 집계 기준도 달라 현재 모델에 바로 대입하지 않습니다.
신림선 주변에서는 이번 다음 분기 성능 개선이 없고, 1년 뒤의 개선도 한 해의 평가입니다. 추가 연도·지역에서 검증이 필요합니다.

## 기존 팀 공유 파일의 역할

- `tram_demand_2030_plan.csv`: 45개 정거장의 계획 수요 조회와 사용자 가정 시나리오에 사용합니다. 서울 과거 점포 정답과 대응하지 않아 ML 입력에서는 제외했습니다.
- `construction_city_markets.csv`: 공구별 공사 영향 상권 52곳 조회에 사용합니다. 위치·공사 시점 대응이 없어 ML 변수로 넣지 않았습니다.
- 신림선 2022년 승하차도 전체 2021~2025년 입력에 일관되게 대응하지 않아 제외했습니다.

## 재현과 파일

작업공간 루트에서:

```sh
d_vision_project/.venv/bin/python d_vision_project/tools/train_shop_prediction.py
```

기존 환경의 scikit-learn 1.6.1을 사용합니다. 별도 학습 환경을 만들 때는 기존 requirements.txt를 따릅니다.
원자료는 수정하지 않습니다. 웹은 scikit-learn을 직접 실행하지 않고 오프라인에서 학습·평가한 저장 결과를 읽습니다.
모델 원본은 `results/shop_ml_20261114/models/`에, 평가·전망·선택 근거는 `data/shop_ml/`에 보존합니다.
원본 SHA-256, 특성 목록, 정답 시점 분리 기록, 고정 seed와 방법을 manifest.json에 기록합니다.
웹 실행본 세 곳에는 같은 평가·전망 CSV와 manifest를 넣었습니다. 모델 pickle은 웹에서 읽지 않습니다.

[국가철도공단 역 정보](https://data.kric.go.kr/rips/M_01_01/detail.do?id=32).
