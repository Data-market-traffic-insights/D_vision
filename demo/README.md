# D·VISION 트램 특화 시연용

> 트램이 바꿀 대전 상권, 계약 전에 미리 봅니다.

대전 트램 계획과 현재 상권 구조를 결합해 창업 후보 입지를 탐색하는 Streamlit 앱입니다. 미래 매출·유동인구·창업 성공을 예측하지 않습니다. 원본 프로젝트를 보존한 작업 복사본에서 개발했으며, 이 폴더는 필요한 코드·데이터만 포함하는 독립 시연본입니다. 저장소의 `demo/` 폴더에서 실행합니다. 배포·공개 링크는 생성하지 않았습니다.

## 실행

권장 Python 3.12. 이 Mac에서는 폴더 안의 독립 `.venv` 설치와 실행을 확인했습니다.

```bash
cd demo
sh run.sh --server.port 8502 --server.address 127.0.0.1
```

다른 위치에서 실행하려면 먼저 이 폴더로 이동합니다. 포트가 사용 중이면 `8502`를 `8510` 등으로 바꿉니다. 브라우저에서 `http://localhost:8502`로 접속하고 종료할 때 터미널에서 `Ctrl+C`를 누릅니다. 원본이나 다른 폴더의 가상환경을 사용하지 않습니다.

다른 컴퓨터로 옮겼거나 가상환경을 다시 만들 때:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
sh run.sh --server.port 8502 --server.address 127.0.0.1
```

가상환경 자체는 기기 간에 복사해 재사용하지 마세요. 배경 지도에는 인터넷 연결이 필요합니다. 외부 공유는 별도 승인과 데이터 권리 확인 후 설정합니다.

## 기능

- 기존 상권 지도 3종, 82개 행정동 상세 분석, 저장된 K=3 결과
- 승인된 트램 근사점 5개의 300m·500m 주요 분석 및 1km 확장 비교
- 반경별 누적 상가 수·추가 띠 범위·업종 구성 비교
- 정거장 비교, 증가·유지·감소 가정과 지상 공사 접근성 점검 안내
- 사용자 조건 부합도 기반 창업 입지 탐색: 기존 다섯 선호 조건·정규화·계산식 유지
- **신규 접근권 편입 후보**: 공식 1호선 22개 역과 검토된 트램 5개를 동일 300/500m 직선거리 기준으로 비교
- 가상 콘텐츠임을 표시한 읽기 전용 시연 커뮤니티

좌표 관리자 UI와 관리자 모듈은 이 시연본에서 제외했습니다. 검색·분석·다운로드는 서버 CSV·JSON을 수정하지 않습니다.

## 기술

Python, pandas, NumPy, Streamlit, Plotly, pydeck. K-means는 기존 scikit-learn 분석 결과를 읽으며 실행 중 재학습하지 않습니다. 따라서 시연 런타임에 scikit-learn·matplotlib를 추가 설치할 필요는 없습니다.

## 빠른 확인

지도 상단 ‘신규 접근권 편입 후보’ → 500m **1,593개** / 300m **1,036개**. ‘트램 연계 시나리오’ → 유성온천 500m **1,663개**, 음식 **442개** / 관저 500m **404개**.

전체 상가 79,691개, 행정동 82개, 업종 10개, 정거장 목록 45개 중 분석 승인 5개를 유지합니다. 지도 상가는 최대 3,000개 고정 시드 표본으로 표시하며 수치·표는 전체 자료로 계산합니다.

데이터 출처와 검증 기준·분석 한계는 [데이터 안내](DATA_SOURCES_AND_LIMITS.md)를 확인하세요. 데이터 공개 조건이 확인되지 않은 자료를 임의로 공개하지 않습니다.
