# 대전광역시 상권 군집화 검증 보고서

원본 79,691행·39열, 상가 ID 79,691개, 행정동 코드 82개를 확인했다. 원본과 전처리 CSV가 일치하며 기존 구/동/업종/동별 업종 집계도 재계산 결과와 일치한다.
입력은 82행·14열이다. 행정동 키 중복, 수치 결측·무한대는 없고 업종 비율 합은 허용오차 1e-10 이내에서 1이다. 다양성도 재계산해 확인했다.

## 특징 설계

업종 비율 10개를 각각 표준화한 뒤 sqrt(0.8/10), log1p(전체상가수)를 표준화한 뒤 sqrt(0.2)를 곱한다. 업종 구성과 규모의 총분산을 80:20으로 설정한 탐색적 설계이며 정답 가중치를 뜻하지 않는다.
비율 합이 1이므로 독립 변수 10개가 아니다. K-means는 독립성을 요구하지 않으므로 합 제약을 유지한 유클리드 거리로 비교한다. 한 업종을 임의로 제거하지 않는다. 로그비 기반 조성자료 분석과는 다르다. 업종별 표준화는 희소 업종에도 같은 분산을 부여하므로 소규모 동의 극단 비율에 민감할 수 있다.
업종다양성은 비율의 함수이므로 입력에서 제외하고 해석용으로 저장했다. 지리 좌표·인구는 입력에 사용하지 않았다. 원안 12개 특징과 규모 가중치 10/20/30% 비교는 feature_comparison.csv에 저장했다. 서로 다른 거리 공간의 실루엣 점수를 직접 성능 순위로 해석하지 않는다.

이번 실행 K=3. 기본 K=3은 수동 검토한 탐색 후보이다. K=2는 실루엣이 가장 높지만 규모에 따른 2분할 성격이 강하다. K=3은 22/25/35개로 분포하며 초기값 0~9와 기준 42 간 ARI 평균 약 0.99로 이번 후보 중 안정적이었다. K=4/5는 초기값 안정성이 낮아지고 K=6~8은 1개 동 군집이 나타났다. K=3의 실루엣은 약 0.119로 낮아 경계가 겹친다. 명확한 자연적 유형이 발견됐다고 주장하지 않는다.
ARI는 동일 데이터의 초기값 변경 안정성만 평가한다. 시간/표본 변화 검증은 아니다. --k로 다른 후보를 실행할 수 있으며 그 경우 아래 통계는 해당 K의 결과다.

## 군집 해석

비율은 행정동별 비율의 단순 평균이며 군집 전체 상가를 합산한 가중 비율과 다르다. 번호는 평균 상가 수 오름차순이다. 명칭은 관측 통계를 요약한 잠정 설명이다.

- 군집 0 — 소규모 음식·소매 비중형: 35개 동, 평균 상가 522.7개. 음식 30.9%, 소매 26.6%, 수리·개인 15.2%, 교육 6.6%.
- 군집 1 — 수리·개인·시설관리·과학기술 상대 비중형: 22개 동, 평균 상가 807.7개. 소매 24.8%, 음식 24.5%, 수리·개인 16.4%, 과학·기술 11.3%.
- 군집 2 — 대규모 복합형: 25개 동, 평균 상가 1745.0개. 음식 29.8%, 소매 25.1%, 수리·개인 11.8%, 과학·기술 10.0%.

## 가중치 민감도

- original_12_features: 실루엣 0.121072, 기본 방법과 ARI 0.2347.
- size_weight_0.1: 실루엣 0.129341, 기본 방법과 ARI 0.2006.
- size_weight_0.2: 실루엣 0.119189, 기본 방법과 ARI 1.0000.
- size_weight_0.3: 실루엣 0.132718, 기본 방법과 ARI 0.9605.

규모 가중치 10%에서 기본 20% 대비 ARI가 약 0.20으로 낮다. 초기값에 대한 안정성과 특징 가중치에 대한 안정성은 다르다. 이번 분류는 80:20 설계에 의존하므로 유형명을 확정된 사실로 제시하지 않는다. 원안 결과도 비교 후보로 보존한다.

## PCA 및 한계

PCA는 군집화에 사용한 가중 공간을 사후 시각화한다. PC1 23.4%, PC2 17.1%의 분산을 설명한다. 2차원 그림의 겹침과 고차원 거리를 동일시하지 않는다.
현재 NumPy 환경에서 sklearn의 거리 계산용 행렬곱에 RuntimeWarning이 발생했다. 경고를 숨기는 대신 유클리드 거리를 좌표 차이로 직접 계산하고 silhouette_samples(metric='precomputed')에 전달한다. K-means 목적함수는 유지한다.
2026년 9월 등록 상가 구성 분석이다. 매출·유동인구·임대료·폐업률을 사용하지 않았으므로 창업 성공률이나 수익성을 예측하지 않는다. 인구와 행정동/법정동 이름을 임의로 연결하지 않았다.

## 실행 및 재현

프로젝트 상위 작업 폴더에서:
```sh
d_vision_project/.venv/bin/python d_vision_project/clustering.py --k 3
```

Python 3.9.6, scikit-learn 1.6.1. 기존 프로젝트 .venv를 사용했고 추가 설치는 없다. 난수 42, n_init=50, 초기값 0~9 비교. 입력/코드 SHA-256, 버전, 특징 목록은 run_metadata.json, 모델 중심 및 변환 파라미터는 model_parameters.npz, 실제 입력 좌표는 transformed_features.csv에 저장했다.
기존 clustering.py는 results/code_before_review/clustering.py에 보존했다. data_preprocessing.py, app.py, 원본/전처리 데이터와 기존 결과 파일은 변경하지 않았다. 실행마다 results/clustering_실행시각/에 저장한다. 지정한 --output-dir가 이미 존재하면 덮어쓰지 않고 실패한다.
