# 실행·프로젝트 구조·좌표 관리

## 실행과 테스트

환경 설치와 실행 명령은 [프로젝트 README](../../README.md)를 따릅니다. `run.sh`는 자체 폴더로 이동한 뒤 전용 `.venv`로 `prototype_app.py`를 실행합니다. 데이터·모듈 경로는 각 Python 파일의 위치를 기준으로 합니다.

```bash
sh run.sh --server.port 8502 --server.address 127.0.0.1
.venv/bin/python -m unittest discover -s . -p 'test_*.py' -v
```

현재 자동 테스트 72개는 루트의 `test_*.py`에 있습니다. `results/`의 코드 사본·지문은 과거 검증 자료이므로 현재 소스로 덮어쓰지 않습니다.

## 주요 파일

| `prototype_app.py` | 현재 사용자 화면 진입점 |

| `prototype_logic.py` | 기존 다섯 조건의 부합도·추천 |
| `tram_analysis.py` | 승인 좌표 검사·Haversine 거리·반경 집계 |
| `tram_scenarios.py` | 현재 반경 지표·정거장 비교·가정별 설명 |
| `tram_access_change.py` | 공식 1호선 전체와 승인된 트램 접근권 비교 |
| `tram_access_ui.py` | 신규 접근권 지도·집계·캐시 |
| `map_visualization.py` | 고정 업종·군집 색상과 지도 계층 |
| `demand_data.py` | 기존 법정동 인구의 행정동 배분 근사 |
| `coordinate_registry.py`, `coordinate_ui.py` | 개발용 좌표 후보 등록·검토·승인·이력 |
| `app.py`, `stage3_ui.py`, `map_ui.py` | 보존한 이전 대시보드 |
| `data_preprocessing.py`, `clustering.py` | 별도 전처리·군집 재현 도구; 일반 앱 실행 중 재학습하지 않음 |

## 데이터 검증

`data/daejeon_clean.csv` 79,691개, `ml_features.csv`, 기존 K=3 결과를 해시·행정동 코드·업종 비율·집계로 검증합니다. `results/`의 일부 JSON 지문과 `analysis_report.md`는 기존 테스트가 실제로 읽으므로 삭제하지 않습니다. 좌표 후보·도면·지도 증빙·CSV·JSON은 유지합니다.

공식 1호선 자료는 `data/metro_line1_stations.csv`와 `metro_line1_sources.json`입니다. 22개 역의 번호·명칭·경위도·출처 해시 검증에 실패하면 신규 접근권 메뉴만 중단합니다. 전체 목록과 좌표 기준은 [데이터 안내](../../results/tram_specialization_20261104/DATA_SOURCES_AND_LIMITS.md)를 확인하세요.

## 좌표 승인

`data/tram_stations.csv`의 45개 중 기존 승인 5개만 분석합니다. [후보 검증 자료](../reviews/정거장_후보_최종검증결과.md)의 권고는 승인 자체가 아닙니다. 도로·교차로 구간·시설 상대 위치·승강장 구간·도면과 지도 차이를 확인한 실제 검토자가 기존 관리자 기능으로 검토해야 합니다. 좌표 이력과 변경 전후 CSV는 `data/tram_coordinate_history/`에 보존합니다. 미승인 후보를 운영 지도나 분석에 임의로 넣지 않습니다.

개발본의 좌표 관리 화면은 서버 파일을 수정할 수 있으므로 외부 공유에 사용하지 않습니다. 별도 시연본에는 관리자 코드가 없습니다.

## 보존 도구와 문서

좌표·CAD·분석 재현 스크립트는 출력 CSV·JSON 또는 보고서를 다시 쓸 수 있습니다. 문서 정리를 위해 실행하지 않았습니다. `tram_expansion_report.py`, `tools/project_organization.py` 등을 직접 실행하면 과거 중간 보고서가 다시 생길 수 있습니다. 앱 실행에 필요한 입력 문서는 아닙니다.

과거 보고서 원문은 `archive/` ZIP에 보관합니다. 원본 프로젝트와 기존 백업을 정리 대상으로 삼지 않았습니다.
