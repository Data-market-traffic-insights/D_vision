# 트램 주변 미래 상권 모델 — 2026-11-14 로컬 개발

기존 `prototype_app.py`를 실행하고 **트램 주변 미래 상권** 메뉴를 선택합니다.
정거장·직선 반경 300/500/1000m·업종·2027~2035년을 선택해 과거 관측과 기본 추정을 비교할 수 있습니다.
대회 제출 태그 `v1.0.0-contest`와 별도의 후속 개발입니다. GitHub 공유 대상은 `project-presentation` 브랜치이며 대회용 `main`과 기존 심사용 웹은 변경하지 않습니다.

좌표 파일이 변경되면 과거 집계를 다시 생성하기 전까지 새 페이지의 사용을 중단합니다.

## 기본 예측

예측 대상은 **대전 전체 동일 업종 1만 개당 해당 정거장 주변 점포 수**입니다.
시 전체의 수집 규모 변동을 일부 완화하기 위한 상대 비중이며, 분류·수집 범위·위치별 편향을 완전히 보정하지는 못합니다.
2024→2025년 교육 3,104→5,584개, 보건의료 744→1,955개의 큰 변동이 있어 인과적 성장으로 단정하지 않습니다.

- 비중 추세: 실제 관측 간 경과 연수에 대해 `log(1+비중)`의 기울기를 계산하고, 분모에 고정 규제값 4를 더해 기울기를 0 쪽으로 축소합니다. 마지막 관측 비중에 연결해 미래로 외삽하며 범위는 0~10,000으로 제한합니다.
- 직전 비중 유지: 마지막 관측의 상대 비중을 유지하는 비교 기준입니다.
- 표의 기본 점포 수는 예측 비중에 **2026년 9월 대전 전체 동일 업종 점포 수를 고정**해서 환산합니다. 시 전체 상가 규모를 별도로 예측하는 모델이 아닙니다.
- 예측 기준일은 선택 연도의 9월 30일입니다. 2025년 관측은 실제 파일의 10월 30일을 사용합니다.

2023~2025년으로 2026년을 예측하는 마지막 시점 검증을 150개 조합에 적용했습니다.
비중 평균 절대오차는 추세 **14.5762**, 직전 비중 유지 **13.6203**(대전 동일 업종 1만 개당)입니다.
따라서 기본값은 직전 비중 유지이며, 추세 모델은 화면에서 비교용으로 선택할 수 있습니다.
같은 검증 구간으로 방법을 선택했으므로 독립적인 최종 평가가 아니며, 겹치는 정거장·반경 조합은 독립 표본도 아닙니다.
선택 방법을 네 시점 전체로 다시 계산합니다. 정규분포 신뢰구간이나 정확도 백분율을 제시하지 않습니다.

## 2030년 계획 수요 가정

팀 공유 파일 `tram_demand_2030_plan.csv`: 45개 정거장의 계획 승차·하차·합계입니다.
공유 안내에 기재된 원출처는 대전광역시 도시철도 2호선 기본계획(변경), 2026년 11월 정보공개 답변입니다.
표 전사·공유 출처: Kang Seungwan, https://github.com/KangSeungWan/Commercial-Area-Analysis .
원표 단위·집계기간·정거장 번호 대응은 미확인입니다. 현재 앱 명칭과 계획 명칭을 모두 표시하며 번호 기준 임시 연결임을 명시합니다.

사용자가 탐색용 가정에 동의한 뒤 0~50% 강도를 직접 선택합니다. 기본값은 **0%**입니다.

`가정 적용 점포 수 = 기본 추정 × [1 + 강도/100 × (정거장 계획 합계 / 45곳 중앙값 − 1)]`

이는 학습한 수요→점포 수 계수가 아니며, 이용객 수가 점포 수를 실제로 증가시킨다는 추정도 아닙니다.
2030년 전에는 적용하지 않고, 이후에는 2030년 계획값이 유지된다는 가정으로 사용합니다.
이 강도 범위는 탐색 UI 범위이며 통계적 신뢰구간이 아닙니다. CSV 내보내기에도 고정 규모·방법·강도·단위 미확인 상태를 포함합니다.

## 이용 조건·재현

`data/forecast/TEAM_SOURCE_LICENSE.txt`와 `TEAM_SOURCE_README.md`에 공유 원문을 보존합니다.
MIT 고지는 코드·문서 적용이며 데이터 이용 조건은 별도입니다. 대전광역시 정보공개 답변(2026-11) 출처를 화면과 문서에 표시합니다.
8989 원자료는 포함하지 않습니다. 원정보공개 답변과 데이터 공개 이용 조건을 확인한 뒤 공개 배포 여부를 결정합니다.

작업공간 루트에서 원본 집계를 재생성하려면:

```sh
d_vision_project/.venv/bin/python d_vision_project/tools/prepare_forecast.py
```

이 도구는 VS Code 원본 및 GitHub 개발본·시연본의 승인 좌표가 같은지 확인하고 세 곳에 동일한 집계를 생성합니다.
실행본별로 현재 디렉터리에서 `python -m unittest test_tram_forecast -v`로 신규 계산·마지막 시점 분리·실제 화면 동작을 확인할 수 있습니다.

## 상권 해석 화면 보완

주변 전체·선택 업종 점포 증감, 업종 구성 비중과 변화(%p), 대전 전체 동일 업종 대비 주변 비중의 상대 변화율을 함께 제공합니다. 시점별 관측 변화와 최근 2025년 10월→2026년 9월 변화를 구분합니다. 2023년을 100으로 둔 비교 그래프는 첫 관측이 0보다 큰 업종에서만 표시합니다.

모든 업종의 최근 수준 유지 기준과 추세 외삽을 나란히 비교하고, 선택 정거장·업종의 한 번의 과거 검증 오차도 표시합니다. 검증 오차를 점포 수로 환산할 때는 검증 대상 연도의 대전 업종 규모를 동일하게 곱하며, 미래 예측구간으로 해석하지 않습니다.

동일 업종·동일 반경의 정거장 5곳 비교와 45곳 중 계획 수요 순위·중앙값 대비 배수를 표시합니다. 순위는 계획 수요 순위이며 미래 매출·성장성 순위가 아닙니다. 교육·보건의료 집계 급변은 별도 표시하고, 기준이 0이면 증가율은 결측으로 둡니다. 전망과 정거장 비교를 각각 CSV로 내보낼 수 있습니다.
