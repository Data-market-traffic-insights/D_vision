# D·VISION 개발용

현재 사용자 웹사이트의 코드·데이터와 좌표 관리 기능, 기본 테스트만 포함합니다. 과거 검증 자료·보고서·코드 사본·CAD·PDF 원문·좌표 변경 이력은 원본 로컬 개발 프로젝트와 백업에 보존하며 이 폴더에 포함하지 않습니다.

## 실행

이 폴더에서 Python 3.12 전용 환경을 만듭니다.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
sh run.sh --server.port 8502 --server.address 127.0.0.1
```

브라우저에서 `http://localhost:8502`에 접속하고 종료는 터미널에서 `Ctrl+C`입니다. 진입점은 `prototype_app.py`입니다. 개발용 좌표 관리 화면은 CSV를 수정하므로 외부 체험에는 [시연용](../demo/README.md)을 사용하세요.

## 포함 기능

상권 지도 3종·82개 행정동 K=3 유형·트램 반경 분석·정거장 비교·공사 등 가정별 시나리오·신규 접근권 편입 후보·기존 다섯 조건의 창업 입지 추천을 유지합니다. 전체 45개 중 승인된 근사 좌표 5개만 분석합니다.

좌표 관리에서 45개 정거장을 각각 검토할 수 있도록 정거장 이미지 45개는 유지합니다. 좌표 저장 시 변경 이력 폴더는 새로 생성됩니다. 과거 이력은 로컬에 보존되어 있으며 새 기록과 혼합하지 않습니다.

## 테스트와 기준값

```bash
.venv/bin/python run_tests.py
```

기본 시험은 23개로 현재 웹사이트·추천 계산·주민 인구 배분·좌표 승인 경계·관리 화면·신규 접근권을 검사합니다. 과거 전체 72개 시험에 포함된 CAD 재현과 단계별 원본 보존 시험은 관련 자료와 함께 로컬 원본에 보존합니다. 이 GitHub 경량 개발본에서 과거 전체 시험을 통과했다고 표현하지 않습니다.

상가 79,691개 / 행정동 82개 / 업종 10개 / K=3. 유성온천 500m 전체 1,663개·음식 442개, 관저 500m 전체 404개. 신규 접근권 후보는 300m 1,036개·500m 1,593개입니다.

## 자료와 한계

[데이터 출처·검증 기준·분석 한계](DATA_SOURCES_AND_LIMITS.md)를 확인하세요. 모든 기본 분석은 현재 등록 상가와 직선거리 기준이며 실제 도보 시간·미래 매출·창업 성공을 예측하지 않습니다. K-means는 저장된 결과를 읽고 실행 중 재학습하지 않습니다.
