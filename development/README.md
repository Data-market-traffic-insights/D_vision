# D·VISION 개발용

대전 현재 상권과 계획된 트램 정거장 접근권을 결합해 창업 후보 입지를 탐색하는 Streamlit 프로젝트입니다. 미래 매출·유동인구·창업 성공을 예측하지 않습니다. 이 폴더는 최신 개발 작업본에서 필요한 코드·데이터·시험을 선별한 업로드용 복사본입니다. 이전 원본과 백업은 로컬에 보존했습니다.

## 실행

이 폴더에 전용 가상환경이 없으면 먼저 생성합니다. 다른 프로젝트의 가상환경을 복사하지 마세요.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
sh run.sh --server.port 8502 --server.address 127.0.0.1
```

브라우저에서 `http://localhost:8502`에 접속합니다. 종료는 터미널에서 `Ctrl+C`입니다. 진입점은 `prototype_app.py`, 보존한 이전 대시보드는 `app.py`입니다.

## 기능과 기준값

- 현재 상권 지도 3종·82개 행정동 상세·기존 K=3 결과
- 트램 정거장 45개 중 승인된 지도 대조 근사점 5개만 분석
- 300m·500m 주요 반경 / 1km 확장 비교·정거장 비교·가정별 시나리오
- 공식 1호선 22개 역과의 신규 접근권 편입 후보 비교
- 기존 다섯 선호 조건에 따른 창업 입지 추천·사용자 조건 부합도

전체 상가 79,691개, 행정동 82개, 업종 10개입니다. 유성온천 500m 전체 1,663개·음식 442개, 관저 500m 전체 404개, 신규 접근권 후보 300m 1,036개·500m 1,593개를 확인합니다. 데이터·기존 승인 좌표·추천 계산식은 문서 정리 과정에서 변경하지 않았습니다.

## 테스트

```bash
.venv/bin/python run_tests.py
```

원본 전체 테스트는 72개입니다. 이 GitHub 구성에서는 과거 CAD 자료를 제외하므로 웹사이트 회귀 68개를 `python run_tests.py`로 실행합니다. CAD 재현 4개는 별도 원본 복원과 경로 확인이 필요합니다. 좌표 등록·승인 화면은 개발용에만 있으며 외부 사용자에게 이 개발본을 공개하지 마세요. 후보 좌표는 승인 전 분석에서 제외합니다.

## GitHub 구성의 제외 자료

대형 `results/cad_review_20261103/`, 과거 백업 ZIP, 가상환경·캐시·로그·개인 설정은 업로드하지 않습니다. 원본 로컬 개발 프로젝트와 백업은 삭제하지 않았습니다. 기존 CAD 감사의 지문·절대경로는 과거 로컬 원본에 대한 기록이며, 원본을 복원하지 않은 환경에서 CAD 재현 시험의 통과를 주장하지 않습니다. 일부 과거 분석 재생성 도구 역시 별도 원천 상가 파일·PDF/CAD 검토 자료가 필요할 수 있습니다. 현재 웹사이트 실행에는 영향을 주지 않습니다.
